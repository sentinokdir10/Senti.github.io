Deep Learning & Mobile Application Development

From facial expression → emotion → music

The application captures a facial image, locates the face, predicts one of seven emotional states and uses that result to recommend a curated Spotify playlist. The project was designed as a complete client-server pipeline rather than only a machine-learning model.

Project Details

What I worked on

The project uses the RAF-DB dataset and MediaPipe for face localization. Seven CNN architectures were trained and compared. EfficientNet gave the best standalone performance at 76%, after which an EfficientNet + MLP fusion model was developed and reported at approximately 80% validation accuracy.

The final architecture uses EfficientNet as a fixed feature extractor and a custom MLP as the classifier head. Dropout was used to reduce overfitting, while preprocessing and augmentation were used to improve robustness.

The application follows a client-server architecture. The Flutter frontend sends a request to a Python Flask API, which handles camera input, preprocessing and inference before returning the detected emotion and playlist information to the app.
